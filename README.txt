EXPLORE BORDERS 0.2.0
For WoW Forever.

Shows area boundaries on your world map so you can see where to run when exploring.
Gold lines are subareas. Cyan lines are outer zone borders.

INSTALL
1. Close WoW.
2. Extract the ExploreBorders folder into Interface/AddOns.
3. Start the game and enable Explore Borders.
4. Open your world map.

COMMANDS
/eborders             On/off
/eborders labels      Show/hide names
/eborders perimeters  Show/hide cyan borders
/eborders status      Info about the current map
/eborders mark note   Save your position with a note

Covers 48 maps so far. See COVERAGE.txt for the full list.
These are terrain boundaries, so discovery might not trigger exactly on the line
everywhere. Some maps and interiors aren't covered yet. Lines stay visible after
you've explored an area.

If anything looks off, include the zone and a screenshot:
https://github.com/Hacker--x/ExploreBorders/issues
