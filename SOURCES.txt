Source build not stated. This is third-party geometry, not an independently
verified current-client extraction or a server discovery-trigger database.

Original rounded world vertices are recovered to nearest 100/3-yard grid indices.
All 812 subareas match their cell counts (125,685 cells); all 59 zone perimeters
also match. Maximum coordinate adjustment is one third of a yard. There are
1,014 subarea rings / 25,334 vertices and 192 perimeter rings / 11,167 vertices.
Counts include rings for holes and disconnected components. Polygon filling uses
even-odd parity; rendering draws all rings. Names and label positions are from
the source. Labels are not recommended discovery waypoints.

48 named maps have positive source UI IDs. 11 instance datasets use negative
source placeholders: these are NOT client UI IDs. They are matched at runtime by
the world-map ID returned by C_Map.GetWorldPosFromMapPos, using its live frame.
World X increases north; world Y increases west. Overviews are not drawn.
