# Explore Borders

Shows area boundaries on your world map so you can see where to run when exploring, instead of guessing where an area starts.

Made for **WoW Forever**. Covers **48 maps** so far.

**[Download Explore Borders](https://github.com/Hacker--x/ExploreBorders/releases/download/v0.2.0/ExploreBorders-0.2.0.zip)**

## On the map

- **Gold lines** = subareas.
- **Cyan lines** = outer zone borders.
- Turn names off if the map gets crowded.

## Install

1. Download the ZIP above.
2. Close WoW and extract the **ExploreBorders** folder into `Interface\AddOns`.
3. Start the game, enable **Explore Borders**, and open your world map.

## Commands

| Command | What it does |
| --- | --- |
| `/eborders` | On/off |
| `/eborders labels` | Show/hide names |
| `/eborders perimeters` | Show/hide cyan borders |
| `/eborders status` | Info about the current map |
| `/eborders mark note` | Save your position with a note |
