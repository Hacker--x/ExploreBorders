# Changelog

## 0.2.0

- Renamed Durotar Borders to Explore Borders.
- Added all supplied subarea outlines: 812 across 47 named maps and two instance datasets.
- Added 59 cyan zone perimeters, bringing overall coverage to 48 named maps and 11 instance datasets resolved through the live client API.
- Kept gold subarea outlines, labels, map zoom/pan support and saved test marks.
- Added `/eborders` and `/eborders perimeters`; old command aliases still work.
- Packaged as a standalone addon. No DurotarBorders folder or importer required.

## 0.1.0

- Initial Durotar Borders prototype: 22 outdoor subareas, map labels and manual test marks.
